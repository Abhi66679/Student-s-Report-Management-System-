Student Management System

A simple console-based student management system written in C.

Features

Admin Role:

* Add, update, delete, and search student records.
* Display all student records.

Staff Role:

* Display and search student records.

Guest Role:

* View-only access to student records.

Data Storage:

* Student records are stored in students.txt.

* The file is auto-created with default records if it doesn’t exist.

Usage:

* Compile the code using a C compiler (e.g., gcc main.c -o sms).

* Run the executable and follow the on-screen prompts.

Built-in Users:

* Admin: Username: admin, Password: admin123

* Staff: Username: staff1, Password: staff123

* Guest: Username: guest, Password: guest

Future Enhancements:

* Encrypt passwords for better security.

* Add more advanced search and sorting capabilities.
